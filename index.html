03 / Mode Behavior

Mode

End Result

Slider values represent the target final frame. Intermediate frames interpolate toward that target.

  • Frame N applies value * (N / total)
  • Bounded output
  • Best for controlled production assets
Mode

Per Step

Slider values are applied fully each frame, causing cumulative change over time.

  • Frame N applies value * N
  • Unbounded accumulation
  • Best for drift and heavy degradation effects
Per Step can saturate quickly at higher frame counts. Reduce values or frame count if clipping appears.

05 / Output Options

Output

Spritesheet + mcmeta

Frames are stacked vertically into a single PNG with matching mcmeta metadata for Minecraft animation.

  • Optional include source frame
  • Frame time and interpolation supported
  • Best for in-game animation workflows
Output

Duplicate Textures

Creates per-frame texture assets in project using original_iter_N naming.

  • Optional include source as iter_0
  • Good for staged variants and manual export
  • Useful for damage or progression states

06 / Troubleshooting

Common Issues

Fast Checks

  • No visible change: verify the active scope and selection state.
  • Output too strong: switch to End Result mode and lower values.
  • Animation not working in Minecraft: confirm png and mcmeta share name and path.
  • Slow preview: lower frame count first.
