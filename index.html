02 / Documentation

Overview

What It Does

I.T.E.M takes any texture — or just a marquee selection or active layer within it — and applies a set of configurable image adjustments across N frames, producing every step of the transition. The output is either a Minecraft-ready animated spritesheet or N individual textures added directly to your project.

All controls are available in any Blockbench format. The live preview panel lets you scrub through every frame before committing to any output.
Scope Detection

What Gets Processed

The plugin automatically selects the narrowest scope available, in priority order. When a sub-region is the scope, adjustments are applied only to that region and composited back into the full texture on output.

PriorityConditionScope
1Marquee selection activeSelected pixels only
2Layers enabled + layer selectedActive layer canvas
3OtherwiseFull texture

For the layer scope, all layers are re-composited on output — the selected layer's pixels are replaced with the processed version while all other layers remain intact, respecting their blend modes and opacity.

Mode

End Result

The slider values represent the desired final state. The plugin linearly interpolates each adjustment across all frames, approaching the target values at the last frame.

  • Frame N applies value × (N / total)
  • Ideal for smooth fade-ins, color shifts, and timed transitions
  • Output is always bounded by the slider values
Mode

Per Step

The slider values represent the cumulative delta applied per frame. Each iteration adds the full adjustment amount on top of the previous.

  • Frame N applies value × N
  • Ideal for drift effects, progressive degradation, unbounded shifts
  • Values accumulate — high frame counts with large deltas will saturate
Image Processing

Adjustments

All adjustments are applied per pixel in the order listed. Each is independently optional — leave unused controls at zero.

ControlRangeDescription
Brightness−100 → 100Additive RGB offset applied uniformly to all channels
Contrast−100 → 100259-factor contrast scaling around the midpoint (128)
Hue−180 → 180Hue rotation in degrees, computed in HSL space
Saturation−100 → 100HSL saturation shift; clamped to 0–1
Opacity−100 → 100Additive alpha channel offset (±255 max)
InvertToggleInverts RGB channels (255 − value) uniformly every frame
Shadows−100 → 100Tone curve adjustment — darkest pixels
Midtones−100 → 100Tone curve adjustment — mid-range pixels
Highlights−100 → 100Tone curve adjustment — brightest pixels
Tone curves use a quadratic weight distribution: shadow weight peaks at v = 0, highlight weight at v = 255, midtone weight at v = 128. Weights always sum to 1, so adjustments are smooth and artefact-free across the full range.
Output

Spritesheet + .mcmeta

All frames are stacked vertically into a single PNG. A .mcmeta file is exported alongside it — drop both into your resource pack as a standard Minecraft animated texture.

  • Include source — optionally prepend the original texture as frame 0
  • Frame time — duration per frame in game ticks
  • Interpolate — enables Minecraft's built-in frame blending
  • Canvas height warning at 32 768 px
Output

Duplicate Textures

Each frame is added to your Blockbench project as a separate texture, named <original>_iter_N.png.

  • Include source — optionally add the original as _iter_0.png
  • Textures are internal — unsaved until you export manually
  • Useful for per-state or per-damage-stage variants
Live Preview

Frame Navigator

The dialog includes a real-time preview panel on the right side. Every slider change immediately reprocesses all frames. Use the ◀ and ▶ arrows to scrub through the sequence before confirming.

  • Frame 0 always shows the unmodified source texture as a reference
  • Frames 1–N show the processed output composited at full texture resolution
  • Preview updates are debounced to a single animation frame for performance
